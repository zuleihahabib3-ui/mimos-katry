# Mimi's Eatery

Ghanaian restaurant website: home, about and contact pages.

## Pages
- `index.html` — home: hero, signature plates, why us, visit details
- `about.html` — story, kitchen quote, values, stats
- `contact.html` — address, phone, hours, booking form
- `about-standalone.html` — the about page as a single self-contained file

## Run locally
Open `index.html` in a browser. No build step, no dependencies.

## Structure
- `styles.css` — all styling, charcoal and gold brand tokens
- `images/` — logo and photography

## Notes
Address, phone, email and chef name are placeholders in `[brackets]`.
The booking form is front-end only until it is wired to a backend.
